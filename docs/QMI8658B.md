# QMI8658B trên ESP32-S3

Ví dụ [QMI8658B_I2C.ino](../examples/QMI8658B_I2C/QMI8658B_I2C.ino) khớp sơ đồ người dùng:

| Kết nối | Giá trị |
|---|---|
| I2C_SDA | ESP32-S3 GPIO8 |
| I2C_SCL | ESP32-S3 GPIO9 |
| VDD/VDDIO, CS, SDO/SA0 | 3,3 V |
| Địa chỉ I²C 7 bit | **0x6A** khi SA0 high; **0x6B** khi SA0 low |
| INT1/INT2 | Không nối; đọc trạng thái qua I²C |
| I²C / USB monitor | 400 kHz / baud chọn 921600 |

Giữ các điện trở kéo lên 5,1 kΩ và tụ nguồn trong sơ đồ. Chân RESV-NC nối high như sơ đồ được datasheet cho phép khi RESV pin 10 đã giữ high.

```sh
pio run -e esp32s3_qmi8658b -t upload
```

Giữ bo yên khoảng 2 giây khi khởi động. Chạy **Start Viewer.cmd**, dùng Chrome/Edge và **Kết nối USB**. Nút **Hiệu chuẩn lại** và **Góc về 0**, dữ liệu CSV dùng như các IMU cũ. Environment dùng USB CDC native ESP32-S3; dùng đúng cổng USB native, hoặc đổi cấu hình Serial nếu bo dùng USB–UART.

Trong dự án khác, sau khi thêm thư viện bằng `lib_deps`:

```cpp
#include <Arduino.h>
#include <IMULibrary.h>
#include <ttimu/ArduinoBus.h>

ttimu::ArduinoI2CBus bus(Wire, 0x6A);
ttimu::IMU imu;

void setup() {
    Wire.begin(8, 9);
    Wire.setClock(400000);
    imu.begin(bus, ttimu::Sensor::QMI8658B, ttimu::Config::qmi8658b());
}
void loop() {
    if (imu.update() && imu.ready()) {
        const auto& d = imu.data();
        // d.roll/pitch/yaw: độ; gyro: rad/s; accel: m/s²; temperatureC: °C.
    }
}
```

Trong ứng dụng thật, kiểm tra giá trị trả về của `begin()`/`error()` như ví dụ đầy đủ.

Profile giữ trục native của sensor, chưa áp hướng lắp PCB. Nghiêng từng trục để xác nhận roll/pitch và dấu theo robot; chỉnh `Config.axes` nếu cần. Không tự áp align của FC F411 cũ lên bo ESP32-S3 này.

## Profile và giới hạn

- Gyro ±2048°/s, **16 LSB/(°/s)**; acc ±16 g, **2048 LSB/g**. Gyro bias lưu theo counts của QMI, không dùng hệ số ICM 16,4.
- Rate class `1000`/`500` trong Config ánh xạ sang ODR danh định **896,8/448,4 Hz**. Getter `sampleRateHz()`/`fusionRateHz()` cho tốc độ danh định sau ánh xạ; `lastDtUs` và timestamp cho chu kỳ thực tế. Tích phân dùng thời gian thực, hệ số lọc dùng rate tương ứng.
- `Config::qmi8658b()` chọn class 1000/1000, gyro anti-alias 180 Hz. Muốn class 500, đổi cả sample/fusion thành 500; các filter phải dưới Nyquist thực. Không dùng preset `inav9()` 4 kHz/2 kHz cho QMI.
- Burst little-endian TEMP_L tới GZ_H được khóa bằng SyncSample. I²C có bước tắt AHB clock gating qua CTRL9 lúc khởi tạo; runtime chỉ đọc trạng thái có giới hạn, không delay chờ khóa. `checkDataReady=false` vẫn giữ giao thức khóa của QMI.
- `Sensor::Auto` cũng nhận dạng được ID 0x05, nhưng ID này dùng chung trong họ QMI8658. Bản này chỉ cam kết cấu hình **QMI8658B**, chưa xác nhận A/C.
- Driver cũng dùng được với RegisterBus SPI 4 dây; ví dụ bo người dùng chỉ dùng I²C. Không triển khai FIFO, I3C, COD, motion engine hay self-test trong bản này.

## Nguồn và kiểm chứng

Driver là mã mới viết theo [QST QMI8658B Datasheet Rev D, QST-PD-B002-22](https://datasheet.lcsc.com/datasheet/pdf/95c5a9b4681f107b4a4ecae3691b9582.pdf?productCode=C5380158), truy cập 18/11/2026: wiring trang 6 và §14.3.1; scale/ODR §3.4–3.6; register/reset §5 và §7.4; khóa mẫu/AHB clock gating §11. Không sao chép driver bên ngoài.

Kiểm thử mô phỏng thanh ghi bao gồm byte order, scale/dấu/nhiệt độ, khóa mẫu, lệnh CTRL9 lỗi/timeout, rate/filter timing, hiệu chuẩn và zero. Build ESP32/STM32 xác nhận tích hợp source; **chưa nạp hoặc đo chất lượng trên QMI8658B thật**. Chưa kết luận noise/drift tương đương ICM42605/42688.
